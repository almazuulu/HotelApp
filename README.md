# HotelApp

Учебное веб-приложение для управления одной гостиницей: каталог номеров, бронирование, личный кабинет клиента и административная панель.

## Планируемый стек

- Backend: Python, Django, Django REST Framework и PostgreSQL.
- Frontend: React, TypeScript и Vite.
- Локальная среда запуска: Docker Compose.

Дизайн интерфейса развивается на основе исходного шаблона `Hotelier_Template`.

## Статус

Проект находится на начальном этапе. README будет пополняться по мере появления структуры приложения, инструкций по запуску и документации API.
